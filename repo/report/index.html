⑥ 확인 방법 4줄

  1. 위치 — 소스 저장소 루트(이 보고서는 report/index.html).
  2. 3단계 이내 — ① git clone 후 폴더로 이동 ② node scripts/run-checks.mjs --who me ③ node scripts/verify-handover.mjs
  3. 통과 모습 — H01 … H10 PASS, pass=10/10, HEADING-OK 7줄과 VERSION-MATCHES-CODE.
  4. 안 될 때 모습 — H10 FAIL(화면 연결 누락), FROZEN-CHANGED(검사 파일이 바뀜), VERSION-DRIFT(인계문서 버전과 소스 불일치) 같은 한 줄이 나옴.
